# Glance

**Лёгкий просмотрщик офисных документов для Windows**

Открывает Word, PowerPoint, Excel, PDF, Markdown, CSV и JSON — без Microsoft Office.<br/>
Правит текст в Word, редактирует TXT, Markdown и JSON.

## ✨ Возможности

| Формат | Просмотр | Редактирование |
|---|:---:|:---:|
| **PDF** | ✅ | — |
| **DOCX** (Word) | ✅ | ✏️ текст |
| **PPTX** (PowerPoint) | ✅ + показ слайдов | — |
| **XLSX** (Excel) | ✅ + диаграммы | — |
| **CSV / TSV** | ✅ | — |
| **Markdown** | ✅ | ✅ живое превью |
| **TXT** | ✅ | ✅ |
| **JSON** | ✅ схема и дерево | ✅ живое превью |

### 📄 PDF
Постраничный рендер на pdf.js, выделение и копирование текста, поиск по всему документу, документы с паролем, кириллические и CJK-шрифты работают офлайн.

### 📝 DOCX
Страницы как в Word: стили, списки, таблицы, картинки, колонтитулы, сноски. Широкие таблицы не обрезаются, страница расширяется под них.
**Правка текста** (`Ctrl+E`) в абзацах и ячейках таблиц; форматирование остального текста сохраняется.

### 📊 PPTX
Слайды с фигурами, таблицами, диаграммами и SmartArt, поиск по тексту, **показ слайдов на весь экран** (`F5`).

### 📈 XLSX
Листы с заливками, шрифтами, границами, объединёнными ячейками, закреплёнными областями, форматами чисел и дат, картинками и **диаграммами**. Строка формул показывает значение или формулу выбранной ячейки.

### 🧾 CSV / TSV
Разделитель и кодировка (UTF-8 / Windows-1251) определяются автоматически.

### 🔖 Markdown
Оформленный просмотр (GFM: таблицы, списки задач, код), локальные картинки, переходы по относительным ссылкам на другие файлы. **Редактор с живым превью** (`Ctrl+E`).

### 🗒️ TXT
Сразу открывается в редакторе, как в Блокноте.

### 🧩 JSON
- **Схема (mind map)**: каждый объект и массив отображается карточкой с ключами, вложенные карточки связаны линиями. Поле перетаскивается мышью, `Ctrl + колесо` масштабирует к курсору, есть кнопка «Вписать в окно». Путь до выбранного значения подсвечивается.
- **Дерево** со сворачиванием, подсветкой типов и путём к значению (`$.items[3].name`), путь можно скопировать.
- Правка значений и ключей двойным кликом в обоих видах.
- **Редактор с живой схемой или деревом** (`Ctrl+E`), ошибки с номером строки, форматирование отступов.
- Большие числа показываются и сохраняются без потери точности.

### 🪟 Общее
- Вкладки, перетаскивание файлов в окно, недавние файлы.
- «Открыть с помощью» и двойной клик по файлу; второй файл открывается вкладкой в уже запущенном окне.
- Масштаб (`Ctrl + колесо`), тёмная тема по системной настройке.
- Сохранение (`Ctrl+S`) не меняет исходную кодировку (UTF-8, UTF-8 BOM, UTF-16, Windows-1251) и переводы строк (CRLF / LF).
- Несохранённые изменения отмечаются точкой на вкладке; при закрытии Glance предложит сохранить.

## 📦 Установка

1. Скачайте `Glance_<версия>_x64-setup.exe` со страницы [**Releases**](https://github.com/thebralin/glance/releases).
2. Запустите установщик. Права администратора не нужны: Glance ставится в профиль пользователя.

Установщик регистрирует Glance для `.pdf .docx .pptx .xlsx .md .txt .json` и родственных форматов, поэтому приложение появится в меню «Открыть с помощью». Чтобы открывать такие файлы двойным кликом, выберите **Открыть с помощью → Выбрать другое приложение → Glance → Всегда**.

> [!NOTE]
> WebView2 уже есть в Windows 10/11. Если его нет, установщик скачает его сам.

|---|---|

| `Ctrl+S` | Сохранить (TXT, Markdown, JSON, DOCX) |

## 🛠️ Разработка

### Требования

- [Node.js 20+](https://nodejs.org)
- [Rust](https://rustup.rs)
- Visual Studio Build Tools с компонентом *Desktop development with C++* ([prerequisites Tauri](https://v2.tauri.app/start/prerequisites/))

### Команды

```bash
npm install
npm run tauri dev      # окно приложения с hot reload
npm run tauri build    # установщик → src-tauri/target/release/bundle/nsis/
npm run dev            # только интерфейс в браузере (без нативных функций)
```

### Сборка в GitHub Actions

Собрать установщик можно без локального Rust: перенесите `ci/github-build.yml` в `.github/workflows/build.yml` и запустите workflow вручную или запушьте тег `v*`. Готовый `.exe` появится в *Actions → Artifacts*.

<details>
<summary><b>⚙️ Как устроено</b></summary>

- **Разбор в WebView.** Rust только отдаёт байты файла (`tauri::ipc::Response`, без base64) и записывает их обратно. `write_file` принимает сырое тело запроса и разрешает только `.txt .md .markdown .json .docx .docm .dotx`.
- **Ленивая загрузка.** Каждый просмотрщик подгружается по требованию, поэтому окно открывается мгновенно.
- **Правка DOCX.** Перед рендером в каждый `<w:p>` копии документа вставляется невидимая закладка с номером абзаца; по ней находится отрисованный `<p>`. Абзац доступен для правки, только если текст, собранный из XML, совпадает с отрисованным. При сохранении пословный diff меняет текст внутри существующих `<w:r>`, поэтому форматирование неизменённых слов остаётся.

</details>

## ⚠️ Ограничения

- Старые бинарные форматы `.doc`, `.xls`, `.ppt` не поддерживаются (Glance покажет подсказку).
- **DOCX** делится на страницы только по явным разрывам и разделам, точной вёрстки Word нет.
- **XLSX**: не отображаются условное форматирование, спарклайны, фигуры и кнопки, сводные диаграммы. Формулы не пересчитываются, показывается значение, сохранённое Excel.
- **PPTX**: анимации и переходы не воспроизводятся, видео не проигрывается.
- Шрифты берутся из системы: если шрифта из документа нет в Windows, он будет заменён.
- **Markdown**: картинки из интернета не загружаются (CSP, приложение работает офлайн), только локальные файлы. Подсветки синтаксиса в блоках кода нет.
- **Правка DOCX** касается только текста: абзацы, форматирование, таблицы и картинки не создаются и не удаляются. Колонтитулы, сноски, поля (оглавление, номера страниц), надписи и абзацы с разрывом страницы доступны только для чтения. Если файл открыт в Word, сохранить его не получится.
- **JSON** строгий: комментарии и лишние запятые (JSONC / JSON5) считаются ошибкой.
- «Сохранить как» и отслеживания изменений файла другими программами пока нет.
