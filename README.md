# Glance

Лёгкий просмотрщик офисных документов для Windows на **Tauri 2**: открывает Word, PowerPoint, Excel, PDF, CSV и JSON без Microsoft Office. В Word можно править текст; TXT, Markdown и JSON — полноценно редактировать и сохранять.

| Формат | Что умеет |
|---|---|
| **PDF** | Постраничный рендер (pdf.js), выделение и копирование текста, поиск по всему документу, пароли, кириллические/CJK-шрифты офлайн |
| **DOCX** | Страницы как в Word: стили, списки, таблицы, картинки, колонтитулы, сноски (docx-preview); широкие таблицы не обрезаются — страница расширяется. **Правка текста (Ctrl+E)**: абзацы и ячейки таблиц, форматирование остального сохраняется |
| **PPTX** | Слайды с фигурами, таблицами, диаграммами и SmartArt (pptx-renderer), поиск по тексту, **показ слайдов на весь экран (F5)** |
| **XLSX** | Листы с заливками, шрифтами, границами, объединёнными ячейками, закреплёнными областями, форматами чисел и дат, картинками и **диаграммами**; строка со значением/формулой выбранной ячейки |
| **CSV/TSV** | Автоопределение разделителя и кодировки (UTF-8 / Windows-1251) |
| **Markdown** | Оформленный просмотр (GFM: таблицы, списки задач, код), локальные картинки, переходы по относительным ссылкам на другие файлы; **редактор с живым превью (Ctrl+E)** |
| **TXT** | Сразу открывается в редакторе, как в Блокноте |
| **JSON** | **Схема (mind map)**: каждый объект и массив — карточка с ключами, вложенные связаны линиями; поле перетаскивается мышью, `Ctrl + колесо` — масштаб к курсору, «Вписать в окно», ветка до выбранного значения подсвечивается. Переключается на дерево со сворачиванием, подсветкой типов и путём к выбранному значению (`$.items[3].name`, копируется); правка значений и ключей двойным кликом (в обоих видах); **редактор с живой схемой / деревом (Ctrl+E)**, ошибки с номером строки, форматирование отступов. Большие числа показываются и сохраняются точно |

Сохранение (`Ctrl+S`) сохраняет исходную кодировку (UTF-8, UTF-8 BOM, UTF-16, Windows-1251) и переводы строк (CRLF / LF). Несохранённые изменения отмечаются точкой на вкладке; при закрытии вкладки или окна Glance предложит сохранить.

Общее: вкладки, перетаскивание файлов в окно, «Открыть с помощью» и двойной клик по файлу (второй файл открывается вкладкой в уже запущенном окне), недавние файлы, масштаб (Ctrl + колесо), тёмная тема по системной настройке.

## Горячие клавиши

| | |
|---|---|
| `Ctrl+O` | открыть файл |
| `Ctrl+W` / средняя кнопка мыши по вкладке | закрыть вкладку |
| `Ctrl+Tab`, `Ctrl+1…9` | переключение вкладок |
| `Ctrl+F`, `Enter` / `Shift+Enter`, `F3` | поиск и переход по совпадениям |
| `Ctrl +` / `Ctrl −` / `Ctrl 0`, `Ctrl + колесо` | масштаб |
| `F5` | показ слайдов (PPTX); `←` `→` `Esc` внутри показа |
| `Ctrl+E` | редактор Markdown / JSON, правка текста Word / обратно к просмотру |
| `Ctrl+S` | сохранить (TXT, Markdown, JSON, DOCX) |

## Установка

Запустите `Glance_0.5.2_x64-setup.exe`. Установка идёт в профиль пользователя (права администратора не нужны). Установщик регистрирует Glance для `.pdf .docx .pptx .xlsx .md .txt .json` (и родственных), поэтому он появится в меню «Открыть с помощью». Если хотите открывать такие файлы двойным кликом, выберите Glance в «Открыть с помощью → Выбрать другое приложение → Всегда».

WebView2 уже есть в Windows 10/11; если его нет, установщик скачает его сам.

## Разработка

Нужно: [Node.js 20+](https://nodejs.org), [Rust](https://rustup.rs) и «Visual Studio Build Tools» с компонентом *Desktop development with C++* (см. [prerequisites Tauri](https://v2.tauri.app/start/prerequisites/)).

```bash
npm install
npm run tauri dev      # окно приложения с hot reload
npm run tauri build    # установщик: src-tauri/target/release/bundle/nsis/
npm run dev            # только интерфейс в обычном браузере (без нативных функций)
```

Сборку под Windows можно получить и без локальной установки Rust: переложите `ci/github-build.yml` в `.github/workflows/build.yml`, запушьте проект на GitHub и запустите workflow — установщик появится во вкладке *Actions → Artifacts*.

## Как устроено

```
src-tauri/            Rust: чтение файлов, аргументы командной строки, single-instance
  src/lib.rs          команды read_file / write_file / file_info / take_startup_files
  tauri.conf.json     окно, CSP, установщик NSIS, ассоциации файлов
  windows/hooks.nsh   хук установщика: своя иконка в Проводнике для PDF / Word / PowerPoint / Excel / Markdown / TXT / JSON
  icons/filetypes/    эти иконки (.ico); перегенерировать: python scripts/make-filetype-icons.py
  capabilities/       разрешения для фронтенда (диалог, «Показать в папке», ссылки)
src/                  TypeScript + Vite, без фреймворка
  main.ts             оболочка: вкладки, тулбар, поиск, drag & drop, горячие клавиши
  platform.ts         обёртка над Tauri API (с фолбэком на обычный браузер)
  viewers/            по одному модулю на формат, общий интерфейс Viewer (types.ts)
    pdf.ts            pdf.js: ленивый рендер видимых страниц + текстовый слой
    docx.ts           docx-preview, расширение страниц под широкие таблицы, режим правки
    docxEdit.ts       правка DOCX: метки абзацев, сверка текста, запись правок в runs document.xml
    pptx.ts           @aiden0z/pptx-renderer + режим показа
    xlsx.ts           ExcelJS → HTML-таблица (стили, форматы через SSF, починка «кривых» файлов)
    xlsxCharts.ts     диаграммы Excel: заворачиваются в мини-PPTX и рисуются тем же рендерером
    markdown.ts       marked + DOMPurify, режим редактора с живым превью
    text.ts           TXT
    json.ts           JSON: дерево, правка на месте, редактор с живым просмотром
    jsonGraph.ts      JSON-схема: карточки, раскладка дерева слева направо, панорама и масштаб
    jsonParse.ts      парсер JSON с позициями в тексте, форматирование
    textEditor.ts     редактор: textarea поверх «зеркала» с тем же текстом (для подсветки поиска)
    textCodec.ts      определение кодировки / BOM / переводов строк и обратное кодирование при сохранении
    domSearch.ts      поиск через CSS Custom Highlight API
  styles/app.css      весь интерфейс; светлая и тёмная темы через CSS-переменные
```

Весь разбор документов происходит в WebView: Rust только отдаёт байты файла (`tauri::ipc::Response`, без base64) и записывает их обратно (`write_file` принимает сырое тело запроса и разрешает только `.txt .md .markdown .json .docx .docm .dotx`).

Правка DOCX: перед рендером в каждый `<w:p>` копии документа вставляется невидимая закладка с номером абзаца, по ней находится отрисованный `<p>`. Абзац доступен для правки, только если текст, собранный из XML, совпадает с отрисованным; при сохранении пословный diff меняет текст внутри существующих `<w:r>`, поэтому форматирование неизменённых слов остаётся. Каждый просмотрщик подгружается лениво, поэтому окно открывается мгновенно.

## Ограничения

- Старые бинарные форматы `.doc`, `.xls`, `.ppt` не поддерживаются (покажется подсказка).
- DOCX делится на страницы только по явным разрывам/разделам — точной вёрстки Word нет.
- В XLSX не отображаются условное форматирование, спарклайны, фигуры/кнопки и сводные диаграммы; формулы не пересчитываются (показывается значение, сохранённое Excel).
- Анимации и переходы в PPTX не воспроизводятся, видео не проигрывается.
- Шрифты берутся из системы: если в документе использован шрифт, которого нет в Windows, будет замена.
- В Markdown не загружаются картинки из интернета (CSP, приложение работает офлайн) — только локальные файлы. Подсветки синтаксиса в блоках кода нет.
- Правка DOCX — только текст: новые абзацы, форматирование, таблицы и картинки не создаются и не удаляются; колонтитулы, сноски, поля (оглавление, номера страниц), надписи и абзацы с разрывом страницы остаются только для чтения. Если файл открыт в Word, сохранить его не получится.
- JSON — строгий: комментарии и лишние запятые (JSONC / JSON5) считаются ошибкой.
- «Сохранить как» и отслеживания изменений файла другими программами пока нет.
